## Workflow
1. Create and checkout branch: `git checkout -b <branch-name>`
2. Stage all changes: `git add -A`
3. Commit with the provided message: `git commit -m "<commit message>"`
4. Push: `git push -u origin <branch-name>`

PR stands for Pull Request.  It's a mechanism on GitHub for proposing that code changes from one branch (usually a feature branch) be merged into another (typically main or master). A PR lets other developers review, discuss, and approve the changes before they're integrated into the main codebase.  The typical workflow is: create a branch → make commits → push → open a PR → review → merge.
